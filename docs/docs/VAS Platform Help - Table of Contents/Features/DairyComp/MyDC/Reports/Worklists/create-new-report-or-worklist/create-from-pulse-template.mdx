The **Template&#x20;**\{\{Buttons-UI.GalleryTab}} page provides all standard reports and \{\{Worklists.worklistCommonUse}}s that are available for your \{\{masterVAS-Terminology.d-airy}} within \{\{masterVAS-Products.Pulse-only}}. Note that reports are shaded in **blue** and \{\{Worklists.worklistCommonUse}}s are shaded in **green**.

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/u4Y5JxLxNrP6Lnvlo7_zB_reports-gallery.png" size="85" isUploading="false" initialPath="../../../../Resources/Images/Platform/dairycomp/Reports/reports-gallery.png" githubPath="Content/Resources/Images/Platform/dairycomp/Reports/reports-gallery.png" position="flex-start" showCaption="false"></Image>

You can find this feature under the :Link[DairyComp/MyDC > Reports/Worklists menu]{label="DairyComp/MyDC > Reports/Worklists menu" overridedLabel="DairyComp/MyDC > Reports/Worklists menu" spaceId docId="4pqZ1d4i2LeoUlvE5Z7gf" version="v2" docAnchorId="#Menu-DairyComp-Reports" loadingMethod="dynamic" newTab="false" githubPath="../../../NavPlatform/Menu.htm#Menu-DairyComp-Reports" href="../../../../../../navigate-pulse/menu-options.mdx"} on the \{\{Buttons-UI.FeaturesSecondary}} tab.

You can customize any standard report or \{\{Worklists.worklistCommonUse}} available in the gallery! \{\{Commands.Click}} the **Customize** button to open the report in [Report/Worklist Builder](ReportWorklistBuilder.htm). After your standard report is customized and saved, the report is added to the [Dairy Reports/Worklists](<../../../../../../../../VAS Platform Help - Table of Contents/Features/DairyComp/MyDC/Reports/Worklists/manage-dairy-reportsworklists.mdx>)page.

See [Build Custom Report or Worklist](ReportWorklistBuilder.htm) to learn more about customizing standard reports and \{\{Worklists.worklistCommonUse}}s.
