<ExpandableHeading>
  ### Required Permissions

  Only users who are assigned to a Role with \{\{RolesPermissions.PermissionNames}} permissions can use this feature. See [Edit Dairy User Permissions](../../../../../manage-dairy-users-and-roles/edit-dairy-user-permissions.mdx) and [Manage Dairy Roles](../../Config/UserMgmtRoles/ManageRoles.htm) for more information.
</ExpandableHeading>

The \{\{masterVAS-Terminology.D-airy-}} \{\{Buttons-UI.DC-Reports}} page includes the reports or \{\{Worklists.worklistCommonUse}}s you customized from the [Template Gallery](DC-ReportsGallery.htm), as well as any other custom reports you created using [Report/Worklist Builder](ReportWorklistBuilder.htm). Note that reports are shaded in **blue** and \{\{Worklists.worklistCommonUse}}s are shaded in **green**.

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/9RLuiYVd_OVBRq9bK8G8D_dairy-reportsworklists-intro.png" size="94" isUploading="false" initialPath="../../../../Resources/Images/Platform/dairycomp/Reports/dairy-ReportsWorklists-intro.png" githubPath="Content/Resources/Images/Platform/dairycomp/Reports/dairy-ReportsWorklists-intro.png" position="flex-start" showCaption="false"></Image>

You can run reports or \{\{Worklists.worklistCommonUse}}s for \{\{today}} or up to 30 days in the future. This option allows you to collect additional data and gives you even more choices when planning tasks and managing your \{\{masterVAS-Terminology.h-erd}}.

You can find this feature under the :Link[DairyComp/MyDC > Reports/Worklists menu]{label="DairyComp/MyDC > Reports/Worklists menu" overridedLabel="DairyComp/MyDC > Reports/Worklists menu" spaceId docId="4pqZ1d4i2LeoUlvE5Z7gf" version="v2" docAnchorId="#Menu-DairyComp-Reports" loadingMethod="dynamic" newTab="false" githubPath="../../../NavPlatform/Menu.htm#Menu-DairyComp-Reports" href="../../../NavPlatform/Menu.htm#Menu-DairyComp-Reports"} on the \{\{Buttons-UI.FeaturesSecondary}} tab.

Follow the steps below to continue:

1. \{\{Commands.Click}} the **See Results** button to open the options window.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/iZ7mx8TGXwF-jyPxdICBX_dairy-reports-report.png" alt caption size="29"}:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/aMepN6znd0OQbh8xKuWl9_report-results-options.png" alt caption size="31"}
2. The date field defaults to today's date. \{\{Commands.Click}} on the date field to change it.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/TIpaa6fz3XIAPAvb3yJgh_date-picker.png" alt caption size="38"}:::hint\{type="info"}
   **NOTE:&#x20;**&#x59;ou cannot select a date in the past, but you can select a date up to 30 days in the future.
   \:::
3. Click the **See Results** button to run the report or \{\{Worklists.worklistCommonUse}}. \{\{masterVAS-Products.Pulse-only}} builds the report or \{\{Worklists.worklistCommonUse}} and displays the results on the [ReportWorklistResults.htm](ReportWorklistResults.htm)[Reports/Worklists Results](ReportWorklistResults.htm) page.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/_Tmmyt4D4N8EyRm0Hqx8V_worklistreport-results-edit2.png" alt caption size="62"}
