<ExpandableHeading>
  ### Required Permissions

  Only users who are assigned to a Role with \{\{RolesPermissions.PermissionNames}} permissions can use this feature. See [Edit Dairy User Permissions](../Features/manage-dairy-users-and-roles/edit-dairy-user-permissions.mdx) and [Manage Dairy Roles](../Features/manage-dairy-users-and-roles/manage-dairy-roles.mdx) for more information.
</ExpandableHeading>
