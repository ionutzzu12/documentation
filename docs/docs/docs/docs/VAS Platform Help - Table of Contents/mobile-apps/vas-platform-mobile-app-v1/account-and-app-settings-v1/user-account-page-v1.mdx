Tap the **User Account** button

at the top right of the screen to open the \{\{Mobile-UI.AppMyAccount}} screen.

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/JzrrIzhpcwe92S7tGcgV1_user-acct-view.png" size="34" isUploading="false" initialPath="../../Resources/Images/Platform/mobile-app/user-acct-view.png" githubPath="Content/Resources/Images/Platform/mobile-app/user-acct-view.png" position="flex-start" showCaption="false"></Image>

At the very bottom of this page, you can find your current mobile app version number (see example below). Within this page, you have the following options:

- **Help Us Improve:&#x20;**&#x57;e love to hear from our customers! Tap this option to let us know how the mobile app can better meet your needs. See [Help Us Improve!](<../../../../../../VAS Platform Help - Table of Contents/get-started/help-us-improve.mdx>) for more information.
- **Sign Out:&#x20;**&#x54;ap this option to sign out of the mobile app.
- **User Settings:&#x20;**&#x54;ap this option to view your mobile app user settings. See [User Settings Menu (v1)](user-settings-menu-v1.mdx) for more information.
