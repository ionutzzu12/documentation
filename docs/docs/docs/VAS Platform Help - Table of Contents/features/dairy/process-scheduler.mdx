Use the **Process Scheduler** calendar to view all your scheduled activities in one convenient location. The calendar provides a monthly view, and clicking on a specific day provides additional details in a side panel.

\{\{masterVAS-Products.Pulse-only}} supports scheduling \{\{Buttons-UI.DC-WorklistsONLY}} and \{\{Buttons-UI.DC-Reports}} to automatically generate on a daily, weekly, monthly, or even hourly basis. See :Link[Schedule Worklists]{label="Schedule Worklists" overridedLabel="Schedule Worklists" spaceId docId="mR8e8Q7zS0Xb16kSDN9PC" version="v2" docAnchorId="#Sched-Worklists" loadingMethod="dynamic" newTab="false" githubPath="ScheduleEditProcess.htm#Sched-Worklists" href="../../../../../VAS Platform Help - Table of Contents/Features/Dairy/Process Scheduler/schedule-or-edit-a-process.mdx"} or :Link[Schedule Reports]{label="Schedule Reports" overridedLabel="Schedule Reports" spaceId docId="mR8e8Q7zS0Xb16kSDN9PC" version="v2" docAnchorId="#Sched-Reports" loadingMethod="dynamic" newTab="false" githubPath="ScheduleEditProcess.htm#Sched-Reports" href="../../../../../VAS Platform Help - Table of Contents/Features/Dairy/Process Scheduler/schedule-or-edit-a-process.mdx"} for instructions on adding those processes. After adding the processes to the schedule, you can view the activities on Process Scheduler.

\{\{Protocols.ProcessScheduler}}also allows you to create and manage email and text alerts for your \{\{masterVAS-Terminology.d-airy}}'s \{\{Protocols.Protocol-common}} tasks. See [Add and Manage Task Status Alerts](<../../../../../VAS Platform Help - Table of Contents/Features/Dairy/Process Scheduler/add-and-manage-task-status-alerts.mdx>) for more information on setting \{\{Protocols.Protocol-common}} task alerts.
