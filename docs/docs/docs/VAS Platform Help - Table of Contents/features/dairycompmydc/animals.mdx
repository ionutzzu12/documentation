The \{\{Buttons-UI.DC-Animals}} page lists all of the animals in your \{\{masterVAS-Terminology.d-airy}}. You can view detailed data for each animal, retrieve an animal's CowCard, and add new animals to the \{\{masterVAS-Terminology.h-erd}}:
