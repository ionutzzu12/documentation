Follow the steps below to continue:

1. Begin by selecting \{\{Buttons-UI.FeaturesMain}} > \{\{Protocols.ProcessScheduler}} from the \{\{masterVAS-Products.Pulse-only}} menu.
2. Click on a date in the \{\{Protocols.ProcessScheduler}} calendar to open a side panel that displays the date's scheduled processes::inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/OQrz2mHcSrBSRrfgYm7oe_dailyview-mastitis-alert.png" alt caption size="58"}
3. Click a process to view its details.This example illustrates details for the \{\{Mastitis}}**&#x20;Events Alert Group** process that we created as an example in [Step 3: Add Alert Groups](<../../../../../../../../VAS Platform Help - Table of Contents/Features/Dairy/Settings (Dairy)/Performance Indicators/Set Up Health Indicators and Alerts/step-3-add-alert-groups.mdx>).:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/BPJCKNLzyyOz6EEup1-ij_dailyview-mastitis-alert-click-intro.png" alt caption size="59"}:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/_osYJYolxBh5rdX8HTa-z_mastitis-alert-details.png" alt caption size="42"}The details note which indicators \{\{masterVAS-Products.Pulse-only}} is tracking for this alert group, which users will be notified if your \{\{masterVAS-Terminology.h-erd}} exceeds the thresholds, and the time of day that notifications will be sent.
4. Click **Edit Alert Group** to edit the details if necessary.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/F_Ocp2PMqLCeJiy1Q7lnJ_mastitis-alert-click-edit.png" alt caption size="37"}::::ExpandableHeading
