The \{\{masterVAS-Terminology.SRS2long}} is a portable hand-held device that allows you to quickly read, record, and transfer \{\{EID}} tag information for the animals in your \{\{masterVAS-Terminology.h-erd}}.

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/XRHCFYeW37fg9TjkagLLC_srs2-stick-reader.png" size="43" isUploading="false" initialPath="../../../ContentShare/TruTest/srs2-stick-reader.png" githubPath="Content/ContentShare/TruTest/srs2-stick-reader.png" position="flex-start" showCaption="false"></Image>

<hint type="warning">
  **IMPORTANT:&#x20;**\{\{masterVAS-Terminology.SRS2long}}s are currently only supported in the Android version of the mobile app. Always charge your scanner to 100% before configuring settings. Expand the sections below to learn more::::ExpandableHeading

  ### Required Setup

  Before you connect the \{\{masterVAS-Terminology.SRS2long}}, download the latest firmware from the [Tru-Test website](https://www.livestock.tru-test.com/en-us/resources/4328#downloads).

  <ExpandableHeading>
    ### Navigation Tips

    The display is not a touchscreen. You can navigate to options using the **Arrow** buttons.

    <Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/Pc9MMumzCkyq4FUtUK8uI_srs2-arrow-buttons.png" size="10" isUploading="false" initialPath="../../../ContentShare/TruTest/srs2-arrow-buttons.png" githubPath="Content/ContentShare/TruTest/srs2-arrow-buttons.png" position="flex-start" showCaption="false"></Image>

    To select an option, press the **Scan** button.

    <Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/CidPOsIlFk9bDFnfWoIem_srs2-scan-button.png" size="10" isUploading="false" initialPath="../../../ContentShare/TruTest/srs2-scan-button.png" githubPath="Content/ContentShare/TruTest/srs2-scan-button.png" position="flex-start" showCaption="false"></Image>

    <hint type="info">
      **NOTE:&#x20;**&#x54;he **Scan** button is also referred to as the \{\{masterVAS-Terminology.R-ead-}} and/or **Select** button in your \{\{masterVAS-Terminology.SRS2long}} user manual.
    </hint>

    To return to a previous menu, press the **Return** button.

    :inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/ndfo4tCQ-fpnODKXSCHUL_srs2-return-button.png" alt caption size="10"}
    \::::
  </ExpandableHeading>
</hint>

Follow the steps below to configure a \{\{masterVAS-Terminology.SRS2long}}:

1. Use the **Arrow** buttons to navigate and press the **Scan** button to select **Settings**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/-XasEJWCBN_Wvl-3uwzwn_srs2-settings.png" alt caption size="19"}
2. Select **General**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/2645wJkm-FCQQeXixKK9g_srs2-general.png" alt caption size="19"}

<ExpandableHeading indent="2">
  ### Set the date and time.

  1. Select **Date/Time**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/5IZ9Nc0c-pInQMAqn72EA_srs2-datetime.png" alt caption size="19"}
  2. Select the current **Date**, **Month**, and **Year**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/ywKI7PUJYng_uO2JwJroI_srs2-date.png" alt caption size="19"}
  3. Set the **Format** to **MM/DD/YYYY**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/aupO6LheXosgjMaymKP2p_srs2-format.png" alt caption size="19"}
  4. Set the **Hour** and **Minute** time settings for your time \{\{zone}}.:::hint\{type="info"}
     **NOTE:&#x20;**&#x54;ime settings are in military time.
     \:::
  5. Press the **Return** button to return to the **General** menu.
</ExpandableHeading>

<ExpandableHeading indent="2">
  ### Set the language and country.

  1. Select **Language/Country**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/JwXwvLT-j2YeMQY2STlgT_srs2-language.png" alt caption size="19"}
  2. Set **Language** to **English**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/ppYFd7FkYNaKqIhrrYEx0_srs2-english.png" alt caption size="19"}
  3. Select your **Country**.
  4. Press the **Return** button to return to the **General** menu.
</ExpandableHeading>

5. Set **Auto Off** to **10m**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/4qkg8nl5Ire300ddZv3mY_srs2-autooff.png" alt caption size="19"}
6. Press the **Return** button to return to the **General** menu.
7. Set **Vibration** to **On**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/Nn-K008SjVqd7Hfnaydu4_srs2-vibration.png" alt caption size="19"}
8. Press the **Return** button to return to the **General** menu.
9. Set **Buzzer** to **Off**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/Sv-O3YC05XOe7teAfKd-x_srs2-buzzer.png" alt caption size="19"}
10. Press the **Return** button to return to the **General** menu.
11. Press the **Return** button to return to the **Settings** menu.
12. Select **Bluetooth**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/nvwcLswyiuyEBdl2tiyeV_srs2-bluetooth.png" alt caption size="19"}
13. Set **Bluetooth** to **Auto**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/nEPAVJZDDerQxvByNOxGG_srs2-bluetooth2.png" alt caption size="19"}

<ExpandableHeading indent="2">
  ### Set advanced Bluetooth features.

  1. Select **Advanced**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/Z029JN3gxNNlrM2Bpf_xI_srs2-advanced.png" alt caption size="19"}
  2. Set **Connect Mode** to **Default**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/99lSzf66Z6GIx8UqIqfQJ_srs2-connectmode.png" alt caption size="19"}
  3. Set **Output** to **Default**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/kq_cToxkn-nPwV5oxgQ81_srs2-output.png" alt caption size="19"}
  4. Press the **Return** button to return to the **Settings** menu.
</ExpandableHeading>

15. Press the **Return** button to return to the **General** menu.
16. Press the **Return** button to return to the **Settings** menu.

<ExpandableHeading indent="2">
  ### Set tag reading features.

  1. Select **Tag Reading**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/RwV-YJAhJpdbY-7evoqiP_srs2-tagreading.png" alt caption size="19"}
  2. Set \{\{masterVAS-Terminology.R-ead-}} \{\{Mode}} to **Continuous**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/L_gDyfV82sy6VgOx-oF-l_srs2-readmode.png" alt caption size="19"}
  3. Set **Tag Format** to **Decimal2**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/NhkRSHNRLCrxKkt8W02Kk_srs2-tagformat.png" alt caption size="19"}
  4. Set **Allow Duplicates** to **Yes**.:inlineImage[]{src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/ljzoyTCWZyxQ-aTAf4rvB_srs2-allowduplicates.png" alt caption size="19"}
  5. Press the **Return** button to return to the **General** menu.
</ExpandableHeading>
