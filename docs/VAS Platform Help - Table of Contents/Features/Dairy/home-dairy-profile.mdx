The \{\{Buttons-UI.DairyProfile}} page is the \{\{masterVAS-Terminology.h-omepage}} for the \{\{masterVAS-Terminology.d-airy}} you are currently viewing. It is displayed by default when you select a \{\{masterVAS-Terminology.d-airy}}.

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/xcaxeLTRpV-s8Sm3NcsdL_dairy-profile.png" size="76" isUploading="false" initialPath="../../../../Resources/Images/Platform/dairy-profile/dairy-profile.png" githubPath="Content/Resources/Images/Platform/dairy-profile/dairy-profile.png" position="flex-start" showCaption="false"></Image>

You can find this feature under the :Link[Dairy menu]{label="Dairy menu" overridedLabel="Dairy menu" spaceId docId="4pqZ1d4i2LeoUlvE5Z7gf" version="v2" docAnchorId="#Menu-Dairy" loadingMethod="dynamic" newTab="false" githubPath="../../../NavPlatform/Menu.htm#Menu-Dairy" href="../../../NavPlatform/Menu.htm#Menu-Dairy"}.

As shown in the example above, the \{\{Buttons-UI.DairyProfile}} page provides \{\{masterVAS-Terminology.d-airy}} information, as well as several helpful shortcuts:

- \{\{masterVAS-Terminology.D-airy-}} Information: The middle left side of the page displays the \{\{masterVAS-Terminology.d-airy}}'s contact information, as well as a description of the \{\{masterVAS-Terminology.d-airy}}'s services. Users with \{\{RolesPermissions.Profile\_Management\_title}} permissions can edit this information. See [Settings (Dairy)](../../DairySettings/Settings-Dairy.htm) to learn more.
- Shortcuts to Common Tasks: The right side of the \{\{Buttons-UI.DairyProfile}} page provides shortcut buttons for the following:\* [Find an Animal](../../CowCards/SearchAnimal-ManageAnimals.htm)
  - [Settings (Dairy)](../../DairySettings/Settings-Dairy.htm)
- Quick Actions: The \{\{Buttons-UI.DairyProfile}} page includes convenient links to common \{\{masterVAS-Terminology.h-erd}} management tasks. The Quick Actions available are based on your permission level for that \{\{masterVAS-Terminology.d-airy}}, and may differ from the example shown.\* [Add Animals](../../DairyComp/Animals/AddAnimals.htm)
  - [Add Embryos](../../DairyComp/Embryo/EmbryoAdd.htm)
  - [Report/Worklist Builder](../../DairyComp/ReportsWorklists/ReportWorklistBuilder.htm)
  - [Download Recent Cowfile (DC Unlimited only)](DownloadRecentCowfile.htm)
  - [Milk Recording](../MilkRecording.htm)
  - [Export Herd Data (MyDC in Brazil only)](ExportHerdData.htm)
- Announcements: The \{\{Buttons-UI.DairyProfile}} page displays a summary of the current \{\{masterVAS-Products.Pulse-only}} Announcements. Click the links in the preview to view the full announcements.
