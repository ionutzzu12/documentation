[Jefo Nutrition](https://jefo.ca/) provides precision nutrition solutions to support animal health, milk performance, and reproduction. When you connect the integration from the \{\{masterVAS-Products.Pulse-only}}[Integrations Gallery](../../Platform/Features/Config/Integrations/IntegrationsGallery.htm), your raw herd data is sent to \{\{Partners.PartnerName}}. This is a one-way data share that you can turn on and off with a single click. See [General Integration Instructions](../../Platform/Features/Config/Integrations/GeneralIntegrationInstructions.htm) to learn more about connecting the intergration!
