[E.I. Medical Imaging](https://www.eimedical.com/) provides state-of-the-art, real-time ultrasound scanners to serve veterinarians and livestock producers worldwide. When you connect the integration from the \{\{masterVAS-Products.Pulse-only}}[Integrations Gallery](../../Platform/Features/Config/Integrations/IntegrationsGallery.htm), your raw herd data is sent to \{\{Partners.PartnerName}}. This is a one-way data share that you can turn on and off with a single click. See [General Integration Instructions](<../Integrations Gallery/general-integration-instructions.mdx>) to learn more about connecting the intergration!
