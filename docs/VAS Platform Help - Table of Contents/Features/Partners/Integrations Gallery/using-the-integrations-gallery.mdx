The gallery provides a brief summary of each partner product or service currently available for integration with \{\{masterVAS-Products.Pulse-only}} and includes search and filter features to help you find specific partners.

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/WTghHwV8pca90zLpfZROs_integrations-gallery-using.png" size="73" isUploading="false" initialPath="../../../../Resources/Images/Platform/config/integrations-gallery-using.png" githubPath="Content/Resources/Images/Platform/config/integrations-gallery-using.png" position="flex-start" showCaption="false"></Image>

On the **Upcoming** tab, you can join betas for one of our new, exciting integrations or simply learn more about what's coming out next. To learn more, see [Upcoming Integrations and Beta Testing](upcoming-integrations-and-beta-testing.mdx).

Expand the sections below to learn more:

<ExpandableHeading>
  ## Find an Integration Partner

  You can scroll through the gallery or use the search and filter features to find integration partners.

  <Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/TuUMOEkyvelXiGuM6n-eB_integrations-gallery-filter.png" size="74" isUploading="false" initialPath="../../../../Resources/Images/Platform/config/integrations-gallery-filter.png" githubPath="Content/Resources/Images/Platform/config/integrations-gallery-filter.png" position="flex-start" showCaption="false"></Image>

  - Type text in the **Search** field to search the list of current partners by name. Once text is typed, click the **Clear Filter(s)** option to clear the text typed.
  - Select **Filters** to open a side panel on the left of the page to filter the list of partners by specialty. Once a filter is applied, click the **X** on a specific filter to remove it. Or, click the **Clear Filter(s)** option to the right of the button to clear all filters.
</ExpandableHeading>

<ExpandableHeading>
  ## Connect an Integration

  <ExpandableHeading>
    ### Required Permissions

    Only users who are assigned a Role with Integrations Management permissions can connect partner integrations. See [Edit Dairy User Permissions](<../../../../docs/VAS Platform Help - Table of Contents/Features/manage-dairy-users-and-roles/edit-dairy-user-permissions.mdx>) and [Manage Dairy Roles](../UserMgmtRoles/ManageRoles.htm) for more information.
  </ExpandableHeading>

  To connect to an integration, click **See Details** or **See Requirements** on any of the integration cards in the \{\{Buttons-UI.FeaturesSecondary}} to open the Partner Integration Details page.

  <Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/0jgPszhqEIrPevQ_TibTf_integrations-gallery-connection.png" size="39" isUploading="false" initialPath="../../../../Resources/Images/Platform/config/integrations-gallery-connection.png" githubPath="Content/Resources/Images/Platform/config/integrations-gallery-connection.png" position="flex-start" showCaption="false"></Image>

  Follow the integration's connection instructions to activate the integration. After you are connected to an integration, you'll see a Connected icon

  <Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/5cIoqRKx3IYgQZzXb8Lvu_integration-connected.png" size="10" caption="connected" alt="connected" isUploading="false" initialPath="../../../../Resources/Images/Platform/config/integration-connected.png" githubPath="Content/Resources/Images/Platform/config/integration-connected.png" position="flex-start" showCaption="true"></Image>

  on the integration card in the \{\{Buttons-UI.FeaturesSecondary}}. See [Partner Integration Details](partner-integration-details.mdx) to learn more about the content you'll see on the page.
</ExpandableHeading>
