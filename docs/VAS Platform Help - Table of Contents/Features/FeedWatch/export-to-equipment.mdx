  ### Required Permissions

  To use this feature, your \{\{General.ProductName}} user account must be assigned to a Role with \{\{RolesPermissions.PermissionNames}} permissions. See [Edit Dairy User Permissions](<../../../docs/VAS Platform Help - Table of Contents/Features/manage-dairy-users-and-roles/edit-dairy-user-permissions.mdx>) and [Manage Dairy Roles](../Config/UserMgmtRoles/ManageRoles.htm) for more information.

The \{\{Buttons-UI.FC-ExporttoEquip}} feature allows you to quickly send any feed changes to \{\{masterVAS-Products.FeedWatchOnPremise}} and out to your equipment. This includes any adjustments to recipes, ingredients, or \{\{DM%}} completed in \{\{masterVAS-Products.FeedWatchOnPremise}} or \{\{masterVAS-Products.Pulse-only}}.

To access this option, select the **Integration Status** button and view the \{\{masterVAS-Products.FeedWatchPlatform}} tab.

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/592dwWCd-PeenuxU67hKy_fwp-export-to-equipment.png" size="24" isUploading="false" initialPath="../../../Resources/Images/Platform/feedwatchplatform/fwp-export-to-equipment.png" githubPath="Content/Resources/Images/Platform/feedwatchplatform/fwp-export-to-equipment.png" position="flex-start" showCaption="false"></Image>

Select **Send Export** to export your feed changes to \{\{masterVAS-Products.FeedWatchOnPremise}} and equipment. The button changes briefly to a

<Image src="https://archbee-image-uploads-qa.s3.amazonaws.com/QjalyvC_Eyr95bGir3p2_/OmTUBrnXhe1zwvgEIf3kl_export-check-save201x29.png" size="10" isUploading="false" initialPath="../../../Resources/Images/Platform/feedwatchplatform/export-check-save_201x29.png" githubPath="Content/Resources/Images/Platform/feedwatchplatform/export-check-save_201x29.png" position="flex-start" showCaption="false"></Image>

to indicate that the export was completed.

<hint type="info">
  **NOTE:&#x20;**&#x49;f multiple exports are requested, they go out to \{\{masterVAS-Products.FeedWatchOnPremise}} and the equipment in the order in which they were sent. For instance, if you select **Send Export** and then complete a DM% change and select **Send Export** a second time, the first request is sent, and then is cleared and replaced with the latest export. Only one request to export exists in the queue at a time.
</hint>
